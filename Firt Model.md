## **My firt lesson:**
**What is the client-server model at a basic level?**

The client is the one that makes a request to the server, and once the server verifies that the request is legitimate, it provides the service, which depends on the company's needs.

We can analyze this using the example of a customer in a coffee shop ordering a coffee, where the purchase is verified through payment with money.

When working with AWS, **we pay for what we use**; resources can be rapidly provisioned and de-provisioned, and billing stops when they are no longer needed, making the process more efficient.

## **Second lesson:**
**What is cloud computing?**

It is the on-demand delivery of IT (information technology) resources over the internet using a pay-as-you-go model.

**Cloud deployment types**

You can deploy cloud resources in several ways: in the cloud, on-premises, and in a hybrid manner.

**Cloud**
With the cloud, you can utilize existing cloud resources and design new apps based on the cloud using combinations of both.

**Locally**
This option does not offer the full range of cloud benefits, but it does provide virtualization and resource management tools; it is typically sought out for specific resources and low latency.

**Hybrid**
This system utilizes dedicated physical servers and combines them with cloud resources into a single network.
