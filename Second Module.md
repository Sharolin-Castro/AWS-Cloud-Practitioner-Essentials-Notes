**What is multi-tenancy in Amazon EC2?**

You only pay for the virtual machines that are running. These are called servers, and they use multi-tenancy, meaning a single physical computer can host many virtual machines. Resources are shared across the physical host, and this resource sharing and isolation is handled by the hypervisor running on the host machine.

When you provision an EC2 instance, you can choose between Windows or Linux as the operating system, and you can also choose which software applications you want to use on that instance.

They are also resizable; you can start with a small instance and scale it up as needed. This also applies to networking and access to requests, making them publicly or privately accessible.

AWS offers virtual machines so you can acquire servers through the Compute as a Service (CaaS) model.
